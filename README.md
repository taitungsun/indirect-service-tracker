分散式資源班教師與特殊教育方案教師適用的輕量化間接服務紀錄工具，協助簡化登錄、統計與報表產出流程。系統採用單一 HTML 檔案架構，免安裝、跨平台、離線可用，資料落地儲存在使用者自己的瀏覽器中。

---

## 主要功能

- **單一檔案架構**：純 HTML 技術構建，不需安裝任何軟體、帳號、伺服器或網路連線，下載後雙擊即可在瀏覽器中開啟使用。
- **紀錄管理與成果統計**：提供新增、編輯、刪除介面；成果報告頁可依日期、學生、服務對象篩選，並提供「本學期／本學年」快速期間，自動統計各服務項目節數、服務對象人次，並以長條圖與圓餅圖呈現各類型佔比。
- **報表輸出**：以 A4 直式列印成果報告與統計圖表，報告標題下方自動帶入學校、學年度學期、教師與統計期間；另提供標準 CSV 格式匯出，方便轉入一般試算表軟體做後續處理。
- **多位學生共用一筆紀錄**：入班支援、諮詢服務等常涉及多位學生，學生姓名可用頓號分隔（如「王小明、李小華」），成果報告篩選單一學生時，多人紀錄也會一併列入。
- **資料安全與個人化**：JSON 備份與還原、超過 30 天未備份自動提醒、儲存用量顯示；支援深色模式切換。

## 快速開始

1. 到 [Releases](../../releases) 下載最新版的 `IST_v1.6.html`（v1.5 以前的檔名為 `IndirectServiceTracker_v1_5.html` 等）。
2. 用瀏覽器（建議 Chrome / Edge）開啟該檔案即可使用。
3. 首次使用時，到「設定與備份」頁填寫學校名稱與教師，這些資料會顯示在成果報告上。

---

## 資料備份與還原

所有資料存放在瀏覽器的 `localStorage`，不會上傳到任何伺服器。**清除瀏覽器資料或更換電腦都會讓資料消失**，請養成定期備份的習慣；超過 30 天未備份時，系統會在頁面上方提醒。

| 操作 | 方式 |
| --- | --- |
| 備份 | 「設定與備份」頁 →「下載備份」，檔名如 `IST_2610121630.json`（西元年末兩碼＋月日時分），內含紀錄與基本資料 |
| 還原 | 「設定與備份」頁 →「還原備份」，選取備份的 `.json` 檔（可還原 V1.0 以後所有版本的備份） |
| 匯出 CSV | 「設定與備份」頁 →「匯出 CSV」，用於行政繳交或外部編輯 |
| 清除資料 | 「設定與備份」頁 →「清除資料」（無法復原，請先下載備份） |

### 從舊版升級

- 用**同一個瀏覽器**開啟新版檔案，即可直接看到原有資料。V1.4 起資料改存於 `ist_` 開頭的鍵名，首次開啟時會自動複製舊資料，舊資料保留不刪除。
- 部分瀏覽器會依檔案存放位置分開儲存，若新版中看不到資料，請用舊版「下載備份」，再於新版「還原備份」即可。
- 若要換瀏覽器或換電腦，請先下載備份，再於新環境還原。

## 技術說明

- **架構**：單一 HTML 檔，原生 JavaScript，不依賴任何框架
- **內嵌套件**：Chart.js 4.5.1、chartjs-plugin-datalabels 2.2.0（皆為 MIT 授權），已內建於檔案中，離線可用
- **字體**：思源黑體（內文）與思源宋體（標題），連網時由 Google Fonts 載入；離線或網路受限時自動改用電腦內建字體（微軟正黑體、新細明體等），功能與版面不受影響。字型以非阻擋方式載入，即使學校網路把連線卡住，畫面也會立即顯示。這是本系統唯一的外部資源，只會傳送一般的網頁請求資訊（如 IP 位址），不會傳送任何紀錄或學生資料
- **圖示**：單色 SVG 圖示內嵌於檔案中，不使用 emoji 與外部圖示庫
- **儲存**：瀏覽器 `localStorage`（約 5 MB；設定頁可查看目前用量）
- **隱私**：資料只存在使用者本機，不會傳送到任何伺服器
