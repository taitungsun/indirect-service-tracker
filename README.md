分散式資源班教師與特殊教育方案教師適用的輕量化間接服務紀錄工具，協助簡化登錄、統計與報表產出流程。系統採用單一 HTML 檔案架構，免安裝、跨平台、完全不連網，資料只儲存在使用者自己的瀏覽器中。

---

## 主要功能

- **單一檔案架構**：純 HTML 技術構建，不需安裝任何軟體、帳號、伺服器或網路連線，下載後雙擊即可在瀏覽器中開啟使用；開啟、操作、列印都不連網。
- **紀錄管理與成果統計**：提供新增、編輯、刪除介面；成果報告頁可依日期、學生、服務對象篩選，並提供「本學期／本學年」快速期間，自動統計各服務項目節數、服務對象人次，並以長條圖與圓餅圖呈現各類型佔比。
- **報表輸出**：以 A4 直式列印成果報告與統計圖表，報告標題下方自動帶入學校、學年度學期、教師與統計期間；長的服務摘要在欄內自動換行。
- **多位學生共用一筆紀錄**：入班支援、諮詢服務等常涉及多位學生，學生姓名可用頓號分隔（如「王小明、李小華」），成果報告篩選單一學生時，多人紀錄也會一併列入。
- **資料安全**：右下角狀態列隨時顯示自動儲存時間與上次備份日期；超過 7 天未備份自動提醒；JSON 備份與還原；資料使用量顯示（與 SEAM、SEIA 共用的合計）。支援深色模式切換。

## 快速開始

1. 到 [Releases](../../releases) 下載最新版的 `IST_v1.7.html`（v1.5 以前的檔名為 `IndirectServiceTracker_v1_5.html` 等）。
2. 用瀏覽器（建議 Chrome / Edge）開啟該檔案即可使用。
3. 首次使用時，到「系統設定」頁填寫學校名稱與教師，這些資料會顯示在成果報告上。

## 資料備份與還原

所有資料存放在瀏覽器的 `localStorage`，不會上傳到任何伺服器。**清除瀏覽器資料或更換電腦都會讓資料消失**，請養成定期備份的習慣：右下角狀態列會顯示上次備份日期，超過 7 天未備份時，系統會在頁面上方提醒。

| 操作 | 方式 |
| --- | --- |
| 備份 | 「系統設定」頁 →「下載備份」，或右下角狀態列的「備份」。檔名如 `IST_2610121630.json`（西元年末兩碼＋月日時分），內含紀錄與學校資訊 |
| 還原 | 「系統設定」頁 →「還原備份」，選取備份的 `.json` 檔（可還原 V1.0 以後所有版本的備份） |
| 清除資料 | 「系統設定」頁 →「清除資料」（會問兩次；無法復原，請先下載備份） |

### 從舊版升級

- 用**同一個瀏覽器**開啟新版檔案，即可直接看到原有資料。V1.4 起資料改存於 `ist_` 開頭的鍵名，首次開啟時會自動複製舊資料，舊資料保留不刪除。
- 部分瀏覽器會依檔案存放位置分開儲存，若新版中看不到資料，請用舊版「下載備份」，再於新版「還原備份」即可。
- 若要換瀏覽器或換電腦，請先下載備份，再於新環境還原。

## 技術說明

- **架構**：單一 HTML 檔，原生 JavaScript，不依賴任何框架
- **內嵌套件**：Chart.js 4.5.1、chartjs-plugin-datalabels 2.2.0（皆為 MIT 授權），已內建於檔案中，離線可用
- **字體**：只用電腦內建字型，不連網下載。電腦已安裝思源黑體（內文）與思源宋體（標題）時直接使用（新版 Windows 11 已內建；其他電腦可從 Google Fonts 免費下載「Noto Sans TC」「Noto Serif TC」安裝），沒有時改用微軟正黑體
- **圖示**：單色 SVG 圖示內嵌於檔案中，不使用 emoji 與外部圖示庫
- **儲存**：瀏覽器 `localStorage`。以本機檔案開啟時，同一個瀏覽器裡的 SEAM、IST、SEIA 共用約 5 MB；「系統設定」頁可查看本系統與合計用量
- **隱私**：資料只存在使用者本機，不會傳送到任何伺服器；系統沒有任何對外連線

## 系列作品

IST 屬於 **SpEdKit 特教工具箱**，由現職特教老師開發，回饋給教學現場。同系列還有 [SEAM 特殊教育行政管理系統](https://github.com/taitungsun/seam)與 SEIA 特殊教育鑑定評估系統（即將推出）。三套系統共用相同的設計原則：單一 HTML 檔、免安裝；資料只存在本機、完全不連網；依官方規範建置；可備份、可列印；免費、非商業。介面也一致：相同的頁首頁尾、狀態列與夜間模式，並以圓底單字圖示區分（SEAM「行」、SEIA「鑑」、IST「間」）。
